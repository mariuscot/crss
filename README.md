The archive contains files supporting CRSS

The archive contains two parts:
1) Python scripts for depicting the cyberattack propagation for 
2) Excel template and examples for cyber resilience calculation using CRSS for CVE-2014-0160 and CVE-2017-0144 

The following subfolder are part of this repository
|
|___scripts : contains the Python scripts executable in Visual Code Studio for CVE-2014-0160 and CVE-2017-0144. 
|___digraphs: contains the .dot files generated by the Python scripts modeling the cyberattacks for the two examples
|___diagrams: contains the .png and .svg files generated by the Python scripts showing graphically the cyberattack propagation for the two examples
|
|___resilience_calculation: contains the Excel file used for calculation of CRSS for CVE-2014-0160 and CVE-2017-0144


Excel file: crss_experimentation
Tabs:
	3 components Template: a template for calculating CRSS illustrated for a generic CVE with CVSS 1, applied to a 3 component target consisting of a sensor, a LAN and a controlling server.
                               The template explains how the different tables relate to each other:
                                    civilian resilience
					participation of each resilience node to resilience formation for cyberattacks from each entry points
                                        aggregation of resilience for each node node 
                                        assigned weight per component type
                                        resilience assignment based on initial resilience R0, CVSS score and participation of node to resilience formation
                                        resilience aggregation per layer
                                        resilience aggregation per system 
                                    military resilience
				        mission goal calculation
                                        criticality
                                        aggregation of mission goal and system criticality to MSF
                                        military node resilience calculation based oin civilian and MSF
                                        military layer and system resilience calculation
